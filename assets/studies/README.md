# Персональные 3D-этюды

Созданы для портфолио в октябре 2026 года. Оригинальная процедурная геометрия в Blender/Python с помощью ИИ-инструментов; чужие модели и текстуры не использованы.

- `field-audio.blend`: концепт настольного аудиоинтерфейса, отдельные элементы корпуса, регуляторов и разъёмов.
- `quiet-workspace.blend`: кабинет с мебелью, светом, предметами и растением.
- `*.png`: общий и детальный ракурсы Cycles, 1500×1050.
- `*-stats.json`: версия Blender и фактическое количество объектов сцены.

Открытие: Blender 4.5 LTS. Материалы процедурные, внешние текстуры не нужны. Камера, свет и модификаторы сохранены в сценах.

Пересборка обоих этюдов из корня репозитория:

```sh
blender --background --threads 4 --python tools/build_blender_studies.py
```

Скрипт перезаписывает обе сцены и рендеры в этой папке. Перед повторной генерацией сохраните отдельно ручные правки `.blend`. Работы не являются производственной или строительной документацией.
